[[Resources/books/MongoDB The Definite Guide/0. Getting Started\|Resources/books/MongoDB The Definite Guide/0. Getting Started]]에서는 MongoDB 서버 인스턴스를 올리고, 로컬에 올라온 서버에 연결하여 셸을 사용했다. 하지만 현재 PC가 네트워크로 접속 가능한 모든 MongoDB 인스턴스에 연결할 수 있다. 시작할 때 `host:port/db`를 지정하면 해당 db를 가리킨다.
```bash
mongosh "<host>:<port>/<db>"
```

`--nodb` 옵션으로 연결하지 않고 셸을 실행할 수도 있다. 이후에 접속하려면 아래와 같이 연결할 수 있다.
```bash
mongosh --nodb

Using Mongosh:		2.5.10

For mongosh info see: https://www.mongodb.com/docs/mongodb-shell/

mongodb://127.0.0.1:27017/?directConnection=true&serverSelectionTimeoutMS=2000
> db = conn.getDB("video")
video
video>
```

#### 셸에서 스크립트 실행하기
셸에서 JavaScript로 작성된 스크립트를 실행할 수 있다. 로컬에서 아래와 같은 JavaScript 파일을 작성해서 로컬 `mongod` 인스턴스에서 실행해 보았다.
```javascript
(function () {
  const now = new Date();
  const collName = "shell_script_test";
  const coll = db.getCollection(collName);

  print("=== mongosh script test start ===");
  print("db:", db.getName());
  print("time:", now.toISOString());

  // 1) 컬렉션 초기화
  coll.drop(); // 없으면 에러 대신 false/예외가 날 수 있는데, 테스트 용도라 OK
  db.createCollection(collName);
  print("created collection:", collName);

  // 2) insert
  const doc = {
    runId: now.getTime(),
    title: "hello from script",
    tags: ["mongosh", "script"],
    counter: 1,
    createdAt: now,
  };
  const ins = coll.insertOne(doc);
  print("inserted _id:", ins.insertedId);

  // 3) find
  const found = coll.findOne({ _id: ins.insertedId });
  print("found title:", found.title);

  // 4) update ($inc, $set)
  const upd = coll.updateOne(
    { _id: ins.insertedId },
    { $inc: { counter: 1 }, $set: { updatedAt: new Date() } }
  );
  print("update matched:", upd.matchedCount, "modified:", upd.modifiedCount);

  print("=== mongosh script test done ===");
})();
```

터미널 실행 내용은 다음과 같다.

#### `.mongorc.js`
전역 변수/함수를 초기화하거나, alias, 기본 함수 재정의 등 MongoDB 셸을 커스터마이징할 때 수정하는 파일이다.

`dropDatabase` 함수나 `deleteIndexes` 함수 같이 실수가 치명적일 수 있는 함수들이 실제로 작업을 수행하지 않도록 설정할 수 있다.
```bash
var no = function() {
    print("Not on my watch.");
};

// Prevent dropping databases
db.dropDatabase = DB.prototype.dropDatabase = no;

// Prevent dropping collections
DBCollection.prototype.drop = no;

// Prevent dropping an index
DBCollection.prototype.dropIndex = no;

// Prevent dropping indexes
DBCollection.prototype.dropIndexes = no;
```
#### Prompt 커스터마이징
셸에 접속하면 기본적으로는 아래와 같은 형식으로 인터페이스가 나온다.
```bash
<db 이름> >
```

이것을 `prompt` 변수를 수정하는 것으로 커스터마이징할 수 있다. 예를 들어, 셸에서 아래와 같이 `prompt` 변수를 설정해보자.
```bash
prompt = function() {
    return (new Date())+"> ";
};
```

그러면 인터페이스가 다음과 같이 나온다.
```bash
Tue Jan 06 2026 13:28:56 GMT+0900 (한국 표준시)>
```
>[!NOTE] 원하는 설정을 계속 사용하고 싶다면, `.mongorc.js` 파일에 해당 내용을 작성해두면, 셸이 시작될 때마다 적용시킨다.

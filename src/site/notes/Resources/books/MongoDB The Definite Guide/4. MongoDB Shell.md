MongoDB는 명령줄에서 MongoDB 인스턴스와 상호작용할 수 있는 JavaScript 기반 셸을 제공한다.

[[Resources/books/MongoDB The Definite Guide/0. Getting Started\|Getting Started]]에서 볼 수 있듯이, 셸은 자동으로 MongoDB 서버에 연결을 시도하기 때문에 셸을 실행하기 전에 `mongod`(서버) 인스턴스를 먼저 실행해야 한다.

셸은 완전한 JavaScript 인터프리터이기 때문에, JavaScript에서 사용하는 변수/연산, 표준 라이브러리(`Math`, `Date`, 문자열 함수 등), 함수 정의/호출을 그대로 사용할 수 있다.

셸에서 줄바꿈이 되었더라도, 문장이 완성되지 않았다고 판단되면 이어서 쓸 수 있다. 그리고 줄바꿈을 여러 번 하면 미완성 입력은 취소된다.
#### MongoDB client
셸이 서버에 연결되면, 기본적으로 어떤 [[Resources/books/MongoDB The Definite Guide/3. Databases\|database]]에 연결되고, 그 연결이 전역변수 `db`에 할당된다. 명령줄에 `db`를 입력하면 현재 연결된 database의 이름을 확인할 수 있다.
```bash
test> db
test
```

`use <db명>`으로 현재 database를 바꿀 수 있는데, 그러면 변수 `db`가 그 database를 가리키게 된다. 이 명령은 순수 JavaScript 문법은 아니지만, 사용 편의(SQL과 비슷한)를 위해 제공된다.
>[!NOTE] `use`는 database를 '선택'하고, 실제 database의 '생성'은 첫 write 작업(`insertOne` 등) 때 일어난다. 즉, 새로 만드는 database라고 하더라도 실제 데이터가 들어가기 전까지는 서버에 존재하지 않는다.

현재 database의 [[Resources/books/MongoDB The Definite Guide/2. Collections\|collection]]은 `db.<collection명>` 명령으로 접근할 수 있다.
#### CRUD
`use video` 명령으로 현재 database를 `video`로 변경하고 실습해보았다.
##### Create
`insertOne` 함수는 [[Resources/books/MongoDB The Definite Guide/1. Documents\|document]]를 collection에 추가한다. `movie`라는, document로 사용될 JavaScript 객체를 만들어서 `blog` collection에 추가해보자.
```bash
video> movie = {"title" : "Star Wars: Episode IV - A New Hope",
| "director" : "George Lucas",
| "year" : 1977}
{
  title: 'Star Wars: Episode IV - A New Hope',
  director: 'George Lucas',
  year: 1977
}

video> db.movies.insertOne(movie)
{
  acknowledged: true,
  insertedId: ObjectId('69563dba0177d99fb46ff868')
}
```

`find` 함수로 `blog` collection에 어떤 데이터가 저장되어 있는지 확인할 수 있다. 데이터를 저장할 때, 그리고 다시 조회할 때, `_id` 필드가 자동 추가된 것을 확인할 수 있다.
```bash
video> db.movies.find()
[
  {
    _id: ObjectId('69563dba0177d99fb46ff868'),
    title: 'Star Wars: Episode IV - A New Hope',
    director: 'George Lucas',
    year: 1977
  }
]
```
##### Read
위에서 `find` 함수로 데이터를 조회해보았는데, `findOne` 함수도 있다. `findOne` 함수는 해당 collection의 데이터 하나를 조회하고 싶을 때 사용한다.
```bash
video> db.movies.findOne()
{
  _id: ObjectId('69563dba0177d99fb46ff868'),
  title: 'Star Wars: Episode IV - A New Hope',
  director: 'George Lucas',
  year: 1977,
}
```

`find` 함수나 `findOne` 함수의 매개 변수에 조건을 지정하여 데이터를 조회할 수 있는데, 이것은 뒤에서 좀 더 자세히 볼 것이다.
##### Update
`updateOne` 함수로 항목을 수정할 수 있다. 여기서 변경 연산자인 `set`이 사용되어야 함을 기억하자. 아래에서는 `reviews`를 key로 가지는 항목이 추가되는데, 이것은 어떤 데이터 배열을 value로 가진다.
```bash
video> db.movies.updateOne({title : "Star Wars: Episode IV - A New Hope"},
| {$set : {reviews: []}})
{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}

video> db.movies.find()
[
  {
    _id: ObjectId('69563dba0177d99fb46ff868'),
    title: 'Star Wars: Episode IV - A New Hope',
    director: 'George Lucas',
    year: 1977,
    reviews: []
  }
]
```
##### Delete
`deleteOne` 함수와 `deleteMany` 함수는 database의 데이터를 영구적으로 지운다. 두 함수 모두 매개 변수를 통해 지울 데이터를 지정한다. 아래는 위에서 추가했던 데이터를 삭제하고, `movies` collection을 조회해본 것이다.
```bash
video> db.movies.deleteOne({title : "Star Wars: Episode IV - A New Hope"})
{ acknowledged: true, deletedCount: 1 }

video> db.movies.find()

```
`deleteMany` 함수는 매개 변수에 맞는 데이터를 모두 지운다.

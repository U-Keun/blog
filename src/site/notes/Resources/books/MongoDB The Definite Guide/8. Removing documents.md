이제 데이터를 삭제해보자. `deleteOne` 함수와 `deleteMany` 함수가 있는데, 두 함수 모두 매개 변수로 삭제할 데이터를 걸러낼 수 있다. 먼저 `deleteOne` 함수로 `_id`가 `4`인 데이터를 삭제해보자.
```bash
video> db.movies.find()
[
  { _id: 0, title: 'Top Gun' },
  { _id: 1, title: 'Back to the Future' },
  { _id: 2, title: 'Gremlins' },
  { _id: 3, title: 'Sixteen Candles' },
  { _id: 4, title: 'The Terminator' },
  { _id: 5, title: 'Scarface' }
]
video> db.movies.deleteOne({"_id" : 4})
{ acknowledged: true, deletedCount: 1 }
video> db.movies.find()
[
  { _id: 0, title: 'Top Gun' },
  { _id: 1, title: 'Back to the Future' },
  { _id: 2, title: 'Gremlins' },
  { _id: 3, title: 'Sixteen Candles' },
  { _id: 5, title: 'Scarface' }
]
```
이 실습에서는 유일한 값을 가지는 `_id` 값으로 [[Resources/books/MongoDB The Definite Guide/1. Documents\|document]]를 삭제했지만, 유일하지 않은 값으로 데이터를 삭제하고자 해도, 가장 먼저 찾게 되는 document를 지운다. 어떤 document가 먼저 발견되는지는 경우에 따라 다른데, 문서가 삽입된 순서, 문서에 어떤 업데이트가 있었는지 등이 그것이다.

조건에 맞는 데이터를 모두 지우려면 `deleteMany` 함수를 사용하면 된다.
```bash
video> db.movies.find()
[
  { _id: ObjectId('695c96bca3922a985d28621d'), title: 'Ghostbusters' },
  { _id: ObjectId('695c96bca3922a985d28621e'), title: 'E.T.' },
  { _id: ObjectId('695c96bca3922a985d28621f'), title: 'Blade Runner' },
  { _id: 0, title: 'Top Gun' },
  { _id: 1, title: 'Back to the Future' },
  { _id: 2, title: 'Gremlins' },
  { _id: 3, title: 'Sixteen Candles' },
  { _id: 5, title: 'Scarface' }
]
video> db.movies.deleteMany({ _id: { $type: "objectId" } })
{ acknowledged: true, deletedCount: 3 }
video> db.movies.find()
[
  { _id: 0, title: 'Top Gun' },
  { _id: 1, title: 'Back to the Future' },
  { _id: 2, title: 'Gremlins' },
  { _id: 3, title: 'Sixteen Candles' },
  { _id: 5, title: 'Scarface' }
]
```
`_id` 값이 `ObjectId` 타입인 document들이 삭제되었다.

`deleteMany` 함수에 매개 변수를 아무것도 넣지 않으면 해당 [[Resources/books/MongoDB The Definite Guide/2. Collections\|collection]]의 document를 모두 삭제할 수 있는데, 그럴 때는 `drop` 함수가 더 빠르다.
```bash
video> db.movies.drop()
true
video> db.movies.find()

```

macOS에서 Claude Code CLI를 사용해보려고 한다. 셸은 `zsh`을 사용 중이고, 설치할 때 `curl` 라이브러리[^1]가 필요하다. 다음과 같은 명령으로 설치할 수 있다.
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

설치 스크립트가 `~/.local/bin`에 Claude를 설치하지만, 이 경로가 자동으로 PATH 환경 변수에 추가되지 않을 수 있다. Claude를 찾지 못한다면, 아래의 명령으로 환경 변수를 추가하고, 해당 내용을 적용시키자.
```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

아래와 같이 설치된 것을 확인할 수 있다.
```bash
 which claude
/Users/{username}/.local/bin/![[스크린샷 2026-01-09 오후 12.34.02.png]]claude
 claude --version
2.1.2 (Claude Code)
```

[[Resources/books/MongoDB The Definite Guide/4. MongoDB Shell - 1\|실습]]을 몇 번 해보면서 [[Resources/books/MongoDB The Definite Guide/2. Collections\|collection]]의 `insertOne` 함수를 사용하여, 하나의 [[Resources/books/MongoDB The Definite Guide/1. Documents\|document]]를 추가해보았고, 자동으로 `_id` key를 추가하는 것도 확인했었다. 데이터를 추가하는 다른 함수도 확인해보자.
#### `insertMany`
`insertMany` 함수를 사용하여 세 개의 document를 추가해보았다.
```bash
video> db.movies.insertMany([{"title" : "Ghostbusters"},
| {"title" : "E.T."},
| {"title" : "Blade Runner"}]);
{
  acknowledged: true,
  insertedIds: {
    '0': ObjectId('695c96bca3922a985d28621d'),
    '1': ObjectId('695c96bca3922a985d28621e'),
    '2': ObjectId('695c96bca3922a985d28621f')
  }
}
video> db.movies.find()
[
  { _id: ObjectId('695c96bca3922a985d28621d'), title: 'Ghostbusters' },
  { _id: ObjectId('695c96bca3922a985d28621e'), title: 'E.T.' },
  { _id: ObjectId('695c96bca3922a985d28621f'), title: 'Blade Runner' }
]
```

`insertMany` 함수는 배열로 여러 document를 한 번에 저장하는데, 네트워크 왕복을 document마다 하는 것이 아니라 묶어서[^1] 보낸다.

`insertMany` 함수에는 두 번째 인자로 `ordered` key에 대한 값을 `true`/`false`로 설정할 수 있다.[^2] `"ordered" : true`인 경우, 입력된 배열 순서대로 삽입을 시도하고, 중간에 하나가 실패하면, 그 시점 이후의 document들은 삽입을 멈춘다. 
```bash
video> db.movies.insertMany([
| {"_id" : 0, "title" : "Top Gun"},
| {"_id" : 1, "title" : "Back to the Future"},
| {"_id" : 2, "title" : "Gremlins"},
| {"_id" : 2, "title" : "Aliens"}])
Uncaught:
MongoBulkWriteError: E11000 duplicate key error collection: video.movies index: _id_ dup key: { _id: 2 }
Result: BulkWriteResult {
  insertedCount: 3,
  matchedCount: 0,
  modifiedCount: 0,
  deletedCount: 0,
  upsertedCount: 0,
  upsertedIds: {},
  insertedIds: { '0': 0, '1': 1, '2': 2 }
}
Write Errors: [
  WriteError {
    err: {
      index: 3,
      code: 11000,
      errmsg: 'E11000 duplicate key error collection: video.movies index: _id_ dup key: { _id: 2 }',
      errInfo: undefined,
      op: { _id: 2, title: 'Aliens' }
    }
  }
]
```

`"ordered" : false`인 경우, 성능을 위해 MongoDB가 삽입 순서를 재배치할 수 있다. 그리고 일부 document가 삽입에 실패해도 나머지는 계속 삽입을 시도한다.
```bash
video> db.movies.insertMany([
| {"_id" : 3, "title" : "Sixteen Candles"},
| {"_id" : 4, "title" : "The Terminator"},
| {"_id" : 4, "title" : "The Princess Bride"},
| {"_id" : 5, "title" : "Scarface"}],
| {"ordered" : false})
Uncaught:
MongoBulkWriteError: E11000 duplicate key error collection: video.movies index: _id_ dup key: { _id: 4 }
Result: BulkWriteResult {
  insertedCount: 3,
  matchedCount: 0,
  modifiedCount: 0,
  deletedCount: 0,
  upsertedCount: 0,
  upsertedIds: {},
  insertedIds: { '0': 3, '1': 4, '3': 5 }
}
Write Errors: [
  WriteError {
    err: {
      index: 2,
      code: 11000,
      errmsg: 'E11000 duplicate key error collection: video.movies index: _id_ dup key: { _id: 4 }',
      errInfo: undefined,
      op: { _id: 4, title: 'The Princess Bride' }
    }
  }
]
```
>[!NOTE] `insertMany` 함수는 삽입만 묶을 수 있지만, `insert`/`update`/`delete`를 한 번에 묶어서 보내는 `bulkWrite` 함수가 따로 있다.
#### 삽입 시 검증
서버는 삽입되는 데이터를 꼼꼼하게 검증하진 않고, 최소한의 구조/크기만 본다.[^3] 그래서 잘못된 데이터가 들어가기 쉬우므로, 신뢰할 수 있는 데이터를 사용해야 한다.

[^1]: batch
[^2]: 기본값은 `true`이다.
[^3]: document의 기본 구조만 확인하고, `_id` 필드가 없으면 추가한다.
